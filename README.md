# ספר הנהלים לקלוד קוד

שיטת עבודה מלאה לפיתוח תוכנה עם קלוד קוד, שמתאימה גם למי שלא קורא קוד. מתקינים אותה בפרומפט אחד, והיא עובדת בכל פרויקט במחשב.

## מה מקבלים
- **מנהל פיתוח וצוות של 9 סוכנים:** ארכיטקט, מעצב, מפתח, כותב בדיקות, סוקר, בודק ממשק, מתעד, ובסוכני AI גם מהנדס מבחנים ובונה אוטומציות. אתה מדבר רק עם המנהל.
- **סדר עבודה קבוע:** `/new-project` (אפיון, שפה עיצובית, תשתית, עבודה), `/new-agent` (סוכני AI ואוטומציות ב-n8n, בקוד או בשילוב: ארכיטקטורת סוכן, טבלאות עזר, מבחנים לפני בנייה), ו-`/feature` (כל פיצ'ר, שינוי או באג, לפי גודל).
- **בדיקת אבטחה שבועית ל-n8n:** השוואה של ההתקנות שלך לפרסומי האבטחה של n8n.
- **שלוש נקודות אישור שלך:** האפיון, התוכנית (כולל הדמיות העיצוב), והמיזוג. כל השאר הצוות עושה לבד.
- **שומרים אוטומטיים:** אין עבודה בלי git, אין סודות ב-commit, הבדיקות רצות לפני "סיימתי", פקודות מסוכנות חסומות או דורשות אישור.
- **למידה מטעויות:** "תיקון = לקח", עם לקחים כלליים, לקחים לכל תפקיד וסקירה שבועית אוטומטית.
- **מעקב:** טיקטים, ריצות בדיקה עם צילומי מסך, ומדריך למשתמש מתעדכן. ב-Notion, או כקבצים בפרויקט למי שלא משתמש ב-Notion.
- **תיעוד עדכני:** Context7 מביא לקלוד את התיעוד העדכני של כל ספרייה.

## איך מתקינים
1. מורידים את התיקייה הזו (או `git clone`).
2. פותחים שיחה חדשה בקלוד קוד, ומדביקים את הפרומפט מ-[SETUP-PROMPT.md](SETUP-PROMPT.md).
3. עונים על כמה שאלות קצרות, ומאשרים את ההתקנות.

## מה צריך
- קלוד קוד בגרסה 2.1.295 ומעלה, ומנוי Pro או Max (Max מומלץ לעבודה עם צוות).
- Node.js 18 ומעלה, git, וחשבון גיטהאב עם הכלי `gh`.
- רשות: Notion עם מחבר פעיל.
