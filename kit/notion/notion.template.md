- עמוד ראשי "מרכז הפיתוח": {{HUB_URL}}
- **פרויקטים**: database {{PROJECTS_URL}}, data source `collection://{{PROJECTS_DS}}`
  - שדות: שם, סטטוס (אפיון / תשתית / בפיתוח / באוויר / מושהה), תיאור, תיקייה במחשב, ריפו בגיטהאב, כתובת האתר, מדריך למשתמש (URL), טכנולוגיות
- **טיקטים**: database {{TICKETS_URL}}, data source `collection://{{TICKETS_DS}}`, לוח "לוח עבודה" לפי סטטוס
  - שדות: כותרת, מספר (TK-n אוטומטי), פרויקט (קשר), טיקט אב / תתי-טיקטים, סוג (פיצר / משימה / באג / תשתית), גודל (קטן / בינוני / גדול), סטטוס (חדש / אפיון / ממתין לאישור תוכנית / בפיתוח / בבדיקות / ממתין לאישור מיזוג / מוזג / באוויר / נחסם / בוטל), תחנה נוכחית (מנהל / ארכיטקט / מעצב / מפתח / כותב בדיקות / סוקר / בודק ממשק / מתעד / ממתין למשתמש), מבחני קבלה, ענף, PR, כתובת ניסיון, תוכנית אושרה, מיזוג אושר, אושר בתאריך, לקחים
- **ריצות בדיקה**: database {{RUNS_URL}}, data source `collection://{{RUNS_DS}}`
  - שדות: שם, טיקט (קשר), סוג בדיקה, תוצאה (עבר / נכשל / עבר עם הערות), בוצע על ידי, סיכום, הוכחות (קבצים), קישור

## כללים
- לפני כתיבה ל-database: fetch ל-data source כדי לקבל שמות שדות מדויקים.
- מדריך למשתמש: עמוד אחד לכל פרויקט, כתת-עמוד של שורת הפרויקט בטבלת הפרויקטים, והקישור אליו נשמר בשדה "מדריך למשתמש".
- צילומי מסך: notion-create-file-upload ואז POST של הקובץ, והצבה בעמוד או בשדה "הוכחות".
- כל ריצת בדיקה היא שורה בטבלת ריצות הבדיקה עם קשר לטיקט. לא מוחקים ריצות שנכשלו: הן ההיסטוריה.
